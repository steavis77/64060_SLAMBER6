Introduction

The purpose of this assignment is to use k-means clustering to explore the structure of the pharmaceutical industry using financial measures. The dataset contains 21 pharmaceutical firms and includes financial variables such as market capitalization, beta, price/earnings ratio, return on equity, return on assets, asset turnover, leverage, revenue growth, and net profit margin. It also includes variables not used in the clustering process, such as median recommendation, headquarters location, and stock exchange.

For the clustering model, I used only the first nine numerical variables listed in the assignment instructions. The remaining variables were used after the clusters were created to help interpret whether there were any patterns by recommendation, location, or exchange.

Standardize the Numerical Variables

The numerical variables are measured on very different scales. For example, market capitalization is measured in billions of dollars, while beta and leverage are much smaller values. Since k-means uses distance calculations, variables with larger scales can dominate the clustering if the data is not standardized.

For that reason, I standardized all nine numerical variables using z-score standardization. I did not apply additional manual weights to the variables. This gives each financial measure an equal opportunity to influence the clustering result.

Choosing the Number of Clusters

The main tuning choice in k-means is the number of clusters, k. I evaluated possible values of k using the elbow method and the average silhouette method.

The elbow method looks at the total within-cluster sum of squares. As k increases, within-cluster variation should decrease, but the goal is to choose a value where additional clusters provide a smaller improvement.

set.seed(123)

wss <- numeric(8)

for (k in 1:8) {
  kmeans_model <- kmeans(pharma_scaled, centers = k, nstart = 50)
  wss[k] <- kmeans_model$tot.withinss
}

plot(
  1:8,
  wss,
  type = "b",
  xlab = "Number of Clusters (k)",
  ylab = "Total Within-Cluster Sum of Squares",
  main = "Elbow Method for Selecting k"
)

wss_table <- data.frame(
  k = 1:8,
  WSS = round(wss, 3)
)

The silhouette method measures how well each observation fits within its assigned cluster compared with other clusters. Higher average silhouette values suggest a better clustering structure.

library(cluster)

silhouette_values <- numeric(7)

for (k in 2:8) {
  kmeans_model <- kmeans(pharma_scaled, centers = k, nstart = 50)
  silhouette_result <- silhouette(kmeans_model$cluster, dist(pharma_scaled))
  silhouette_values[k - 1] <- mean(silhouette_result[, 3])
}

plot(
  2:8,
  silhouette_values,
  type = "b",
  xlab = "Number of Clusters (k)",
  ylab = "Average Silhouette Width",
  main = "Average Silhouette Method for Selecting k"
)

silhouette_table <- data.frame(

Based on the elbow and silhouette results, I selected k = 3. This choice provides an interpretable number of clusters for a small dataset of only 21 firms. A larger number of clusters would create very small groups, which may be harder to interpret and may overfit the specific sample.

Assign Descriptive Cluster Names

To make the results easier to interpret, I assigned descriptive names based on the financial profile of each cluster. The cluster with the highest average market capitalization and strong profitability is labeled as large profitable established firms. The cluster with the highest beta and leverage is labeled as small high-risk growth firms. The remaining cluster is labeled as mid-sized valuation or transition firms.

cluster_summary <- aggregate(pharma_numeric, by = list(Cluster = pharma$Cluster), mean)

large_profitable_cluster <- cluster_summary$Cluster[
  which.max(scale(cluster_summary$Market_Cap)[,1] + scale(cluster_summary$Net_Profit_Margin)[,1] + scale(cluster_summary$ROA)[,1])
]

high_risk_cluster <- cluster_summary$Cluster[
  which.max(scale(cluster_summary$Beta)[,1] + scale(cluster_summary$Leverage)[,1] + scale(cluster_summary$Rev_Growth)[,1])
]

cluster_summary$Cluster_Name <- "Mid-Sized Valuation / Transition Firms"
cluster_summary$Cluster_Name[cluster_summary$Cluster == large_profitable_cluster] <- "Large Profitable Established Firms"
cluster_summary$Cluster_Name[cluster_summary$Cluster == high_risk_cluster] <- "Small High-Risk Growth Firms"

The large profitable established firms cluster is characterized by larger market capitalization and stronger profitability measures such as return on equity, return on assets, and net profit margin. These firms appear to represent the more established pharmaceutical companies in the dataset.

The mid-sized valuation or transition firms cluster generally has lower profitability than the large profitable group and tends to show higher price/earnings ratios. This may suggest firms that investors value based on future expectations or firms that are in a less mature financial position compared with the strongest large-cap companies.

The small high-risk growth firms cluster is characterized by smaller market capitalization, higher beta, higher leverage, and higher revenue growth. These firms appear to be more volatile and potentially more growth-oriented, but also riskier from a financial perspective.

Conclusion

The k-means clustering analysis produced three interpretable groups of pharmaceutical firms. The data was standardized before clustering so that all numerical variables had equal weight in the distance calculations. The final model used k = 3 because it provided a useful balance between model simplicity and interpretability for a small dataset.

The clusters can be summarized as large profitable established firms, mid-sized valuation or transition firms, and small high-risk growth firms. These groups differ mainly by market capitalization, profitability, leverage, beta, and revenue growth. The variables that were not used to form the clusters showed some additional patterns, especially exchange listing, but the main cluster structure was based on the numerical financial measures.
